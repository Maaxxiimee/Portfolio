Receuil de besoins et création d'un site web

But du projet :

Réaliser un site web sur les jeux olympique de Paris 2024.

Description du projet :

Dans ce projet nous devions, en groupe de 3 ou 4, à analyser un receuil des besoins afin de produire un site web à la demande d'un client. Plusieurs livrables étaient attendus comme par exemple un résumé du cahier des charges, une charte graphique et bien entendu le site web.

Ce que j'ai fait sur le projet :

Conception & programmation d'un site web, analyse du cahier des charges, rédaction d'un compte rendu, test

Compétences et capacités travaillés durant le sujet :

Concevoir une chartge graphique, concevoir un site web sur Figma, programmer un site web HTML / CSS / JS, faire des tests et débuger un code, travailler en équipe, rédaction d'un compte rendu
